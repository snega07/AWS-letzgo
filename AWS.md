## Amazon Webservice

AWS is one of the leading cloud service providers. It offers a wide range of computing, networking, storage, database, security, and application services. Organizations can provision infrastructure on demand and pay only for the resources they use.

Cloud computing is the on-demand delivery of computing resources like servers, storage, and databases over the internet, with pay-as-you-go pricing. It eliminates the need to own and maintain physical infrastructure.

**Key Characteristics of Cloud Computing**
- On-demand provisioning
- Elastic scalability
- Pay-as-you-go pricing
- Managed services
- API-driven infrastructure
- High availability and reliability
- Shared Responsibility Model
- Cloud Provider (AWS)

**AWS is responsible for Security of the Cloud, including:**

- Physical data centers
- Hardware
- Networking infrastructure
- Hypervisors
- Global infrastructure
- Customer

**Customers are responsible for Security in the Cloud, including:**

- Applications
- Data
- User access management
- Operating systems (depending on service)
- Network configurations
- Encryption settings

👉 Cloud provider (like Amazon Web Services):
Hardware
Data centers
Networking
👉 You (customer):
Applications
Data
Access control

**Private cloud** is where companies maintain their own data centers and maintain it and run their application on them. 

Owned/controlled by a single organization
Can be on-premise or hosted
Full control over infrastructure

**Characteristics:**

Owned or controlled by one organization
Can be hosted on-premises or by a third-party provider
Full control over infrastructure
Higher maintenance responsibility

**Examples:**

VMware vSphere
OpenStack environments

**Public clouds** are cloud providers who build and take care of the data centers as vendors don’t want to worry about maintenance of the servers. This helps lots of small and mid scale companies to use resources from public cloud providers instead of building and maintaining their own servers.

**Characteristics:**

Managed by cloud providers
Shared infrastructure
Highly scalable
Pay-as-you-go model

**Examples:**

Amazon Web Services
Microsoft Azure
Google Cloud

**Hybrid Cloud**
Important concept you should include:
Combination of private + public cloud

**Example:**

Sensitive customer data stored in a private cloud.
Applications and web servers hosted in AWS.

**Benefits:**

Greater flexibility
Better compliance handling
Cost optimization
Gradual cloud migration


**Advantages:**

- Vendor don’t want to worry about maintenance
- Own and Pay only for what they use
- No waste of resources
- Large variety of services provided
- Large community support

**Disadvantages**

- Security can be considered even if they provide a Virtual private cloud services. Few vendors won’t trust to store their data in the cloud
- Third party dependencies. Any security compromise will affect whole users
- They don’t have full control over the infrastructure
- Vendor lock-in
 → Hard to move between providers
- Dependency on internet
 → No internet = no access
- Misconfiguration risks
 → Most breaches happen due to wrong IAM/S3 settings
